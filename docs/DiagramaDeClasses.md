# Diagrama de Classes

## Versão inicial do diagrama de classes do projeto

A versão inicial do diagrama de classes conta com quatro classes:
* **TabelaHash:** A classe responsável por implementar uma tabela hash que faz uso de árvores binárias nos seus buckets.
* **ArvoreBinaria:** A classe responsável por implementar a estrutura de dados árvore binária, que utiliza nós de árvore para organizar os dados na estrutura.
* **NoArvore:** A classe responsável por armazenar as informações de um veículo, e os filhos à esquerda e à direita.
* **Veiculo:** A classe responsável por armazenar as informações de um veículo, como placa (que funciona como uma chave primária), cor e ano.
